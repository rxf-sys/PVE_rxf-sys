## Tools

- **draw.io** (kostenlos): https://app.diagrams.net/
  - Dateien koennen direkt in GitHub bearbeitet werden
  - VS Code Extension: "Draw.io Integration"
- **Excalidraw** (kostenlos): https://excalidraw.com/
- **Mermaid** (in GitHub Markdown nativ unterstuetzt)

## Diagramme erstellen

1. draw.io oeffnen
2. Datei aus diesem Verzeichnis laden
3. Bearbeiten
4. Als `.drawio` und optional als `.png` speichern
5. Ins Repository committen
